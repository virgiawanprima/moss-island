# CI dokumentasi, README HTML, dan warna pembatalan

Permintaan: jangan jalankan pemeriksaan kode untuk perubahan Markdown saja; README memakai HTML yang lebih tertata; bedakan warna tombol pembatalan agar tegas.

CI: job changes Ubuntu5menit memakai dorny/paths-filter@v3, PR lewat API read-only dan push dibandingkan commit sebelumnya pada branch. Filter negasi !**/*.[mM][dD] mencakup berkas tersembunyi dan folder bertingkat. Job Windows mempertahankan nama lama, dilewati hanya ketika deteksi berhasil dan seluruh perubahan Markdown. Manual tetap full; deteksi gagal tidak diam-diam membuat checks kode dilewati. Tidak memakai paths-ignore pada trigger karena required checks bisa pending. Sumber: https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax dan https://github.com/dorny/paths-filter . Job deteksi singkat tetap berjalan pada docs-only, bukan nol workflow. Perubahan workflow sendiri adalah non-Markdown sehingga pemeriksaan penuh berjalan pada commit ini.

README: header HTML terpusat, aset Momo SVG lokal dengan alt, teknologi, navigasi internal, details/summary untuk perilaku kebun dan aturan lint. Tidak mengubah diagram Mermaid atau mengklaim dukungan native tambahan. Pratinjau Markdown lokal diperiksa, bagian lipat dibuka; renderer lokal bukan tampilan GitHub1:1 dan tidak merender Mermaid. Alat YAML/Markdown sementara di .tmp/doc-check diabaikan Git, bukan dependensi aplikasi. Charset preview diperbaiki; README sumber UTF-8 tidak rusak.

UI: Batalkan rencana dan Ya batalkan memakai merah#9f3942, putih bold, border dan focus ring; hover#b5434e, active#852e37. Kontras putih masing-masing6.69:1/5.42:1/8.60:1. Lanjutkan rencana tetap netral. Label eksplisit dan konfirmasi tetap dipertahankan, tidak hanya mengandalkan warna. Uji web membuka Rencana, membuka konfirmasi, lalu memilih Lanjutkan rencana; plan disembunyikan saat konfirmasi tetap bekerja. Native tidak dijalankan.

Verifikasi: YAML parse lulus, lima kasus filter aktual lulus (root/nested/hidden Markdown, campuran kode, YAML workflow, Markdown dihapus, lockfile). Pola awal tanpa slash tidak mencakup nested bracket glob; diperbaiki sebelum commit. npm test176/176, lint tanpa warning, build dan diff check lulus. Tidak mengubah Rust. Eksekusi workflow remote masih perlu dipantau; simulasi filter lokal tidak menggantikan run GitHub.
