# Audit 013 — Pengingat minum di fase istirahat

Tanggal: 2026-11-04. Permintaan disetujui: hapus tab Minum/pencatatan air dan pindahkan pengingat ke Focus. Saat fase break aktif, label tab menjadi Istirahat, pulau diganti lingkaran sisa waktu, serta pengingat minum dan rilekskan tubuh. Saat kembali fokus, panel pulau dan label Focus kembali. Mode minimize/pet tidak diubah.

Implementasi: src/timer/restView.ts memetakan fase/status/sisa detik mesin ke tampilan. Ring memakai rasio waktu tersisa (penuh ke kosong), tidak memiliki interval lain. Status pause/waiting dan pemulihan sesi ikut mesin. Pengingat native fokus selesai menyebut minum jika fase berikutnya istirahat. Tab/panel minum, pencatat volume/gelas, scheduler periodik dan field skema minum dihapus. Sanitizer mengabaikan field lama sambil mempertahankan jadwal, snapshot timer, pohon, musim dan progres fokus. README diperbarui.

Berkas: index.html, src/main.ts, src/styles.css, src/types.ts, src/storage.ts, src/timer/pomodoroPlan.ts, src/timer/restView.ts, tests/test_suite.ts, README.md.

Verifikasi: ESLint tanpa warning, npm test169/169, npm run build berhasil. Tes168 mencakup ring penuh/setengah/nol, nilai tidak valid, jeda/waiting/completed. Tes169 memakai mesin asli untuk fokus-istirahat-fokus, restore dan reset serta render state. Ekspektasi tes lama diubah karena tab/data minum memang dihapus; kontrak media tidak dilonggarkan.

Preview Edge terisolasi: snapshot fokus berakhir2 detik -> break berjalan, tab Istirahat/ring muncul; pause dan reload tetap break paused; deadline break berakhir -> Focus kembali. Tidak ada tombol tab Minum. Screenshot horizontal1000x400 dan vertikal520x700 diperiksa; ring dan tombol tidak bertumpuk. Screenshot di .tmp (diabaikan Git). Ini uji browser dengan jam mesin nyata dan data uji, bukan bukti notifikasi native atau layar/DPI lain. Desktop Tauri pengguna dibaca lewat screenshot: Focus dan Musik tampil tanpa tab Minum; sesi pengguna tidak diubah untuk memaksakan fase break. Tidak mengukur frame time atau menguji pembaca layar.

Tinjauan antislop after: memakai palet/typography yang ada, aksen break lavender sudah tersedia, tanpa animasi dekoratif baru. SVG ring dekoratif aria-hidden, teks waktu role=timer, status jeda terpisah role=status agar setiap detik tidak diumumkan sebagai live region. Layout mengikuti ruang pulau dan mempertahankan tinggi308px. CSS diurai PostCSS/build dan dibandingkan visual. Rust tidak diubah sehingga tes Rust tidak diulang.

Gotcha: jangan memecah selector CSS dengan koma biasa karena :is(...) juga mengandung koma; gunakan parser CSS. Normalisasi LF diperlukan untuk tes string CSS. Data uji yang ditulis sebelum reload dapat ditimpa penyimpanan pagehide; seed pada init sebelum modul aplikasi berjalan. Semua masalah iterasi tersebut sudah diperbaiki dan verifikasi akhir diulang.
