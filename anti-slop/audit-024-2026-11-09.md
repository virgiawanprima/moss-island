# Audit landing page FigCraft

**Arah baca:** landing page unduhan Moss Island untuk pengguna Windows, memakai bahasa visual aplikasi Moss Island; ENERGY 2 / RHYTHM 2 / MOTION 1. Tujuan: pengguna memahami produk lalu menemukan unduhan installer.

**Cakupan:** inspeksi visual FigCraft `design/landing-page.moss-island.figcraft`, gambar halaman 620 × 1600 pada skala 0.516, inspeksi font dan file lokal di `landing-page/dist/assets/`, serta pembandingan dengan token `src/styles.css`. Tidak mengubah file desain atau aplikasi.

**Acuan aplikasi:** Departure Mono; latar `#101917`, panel `#17231F`, surface `#22332C`, border `#35483E`, teks utama `#F2F1DC`, teks sekunder `#A6B3A6`, mint `#C4F59B`, hijau `#71BA83`. Rincian awal desain web yang berbeda (`#f4f3e8`, `#193e30`, Georgia) memang berasal dari preview landing page, bukan token utama aplikasi.

## Temuan

### 1. HIGH — Placeholder menggantikan aset lokal Moss Island

Di header, portrait Meet, ikon download/footer, sapling dan tree terlihat kotak hijau generik, sementara aset `momo.svg`, `momo-wave.svg`, `sapling.svg`, `tree.svg`, dan `island.svg` tersedia secara lokal. Ini melemahkan identitas yang sudah disediakan proyek dan berlawanan dengan permintaan untuk memakai aset lokal (R-22, R-38). **Saran:** impor SVG sebagai layer editable melalui `file.import` (bukan `image.place`, yang pada percobaan terdahulu menolak SVG), lalu ganti placeholder; pakai PNG lokal untuk tampilan produk. Jalur import tersedia di katalog FigCraft, belum diuji pada file ini.

### 2. MEDIUM — Palet dan tipografi tidak sama dengan aplikasi

Inspeksi `file.fontReport` menemukan lima heading ber-font Georgia; bidang lain memakai Departure Mono. Warna utama masih mengikuti preview landing page (`#f4f3e8`, `#e8eddd`, `#193e30`, `#203f32`), bukan token aplikasi. Ini membuat pengalaman unduhan tampak sebagai brand visual berbeda dari aplikasi yang akan dipasang (R-06, R-20). **Saran:** selaraskan seluruh keluarga teks ke Departure Mono dan gunakan token warna proyek secara konsisten; hierarki heading dibedakan lewat ukuran/berat dan ruang, bukan font asing.

### 3. MEDIUM — Tampilan produk terlalu kecil dan berulang

Pada demo Product, screenshot `product-focus.png` ditempatkan hanya 300 × 143 px di dalam preview 850 × 240 px; screenshot itu sendiri sudah berisi UI timer/kebun. Timer dan tombol Mulai yang digambar terpisah mengulang isi screenshot, sehingga preview produk berlapis dan detail produk sulit dibaca (C-3, R-22). **Saran:** tampilkan screenshot lokal sebagai visual utama yang lebih lebar, atau buat mock UI editabel yang tidak menumpuk screenshot berisi UI; jangan gunakan keduanya untuk menyampaikan informasi sama.

### 4. MEDIUM — Kotak unduhan terlalu rapat terhadap tepi section

Download section tingginya 520 px; kotak mulai pada y=88 dengan tinggi 430 px sehingga menyisakan hanya 2 px di bawahnya. Screenshot halaman memperlihatkan kotak hampir menempel pada batas bawah hijau, mengurangi ruang napas dan dapat terlihat terpotong saat ukuran dibaca/diubah (R-05, C-4). **Saran:** tambah tinggi section atau ringkas isi kotak agar tersedia padding bawah yang seimbang dengan padding atas.

### 5. HIGH — CTA dan navigasi belum memiliki interaksi prototype

Tombol "Bawa pulangnya", "Unduh untuk Windows", nav "Kenalan dulu" / "Unduh Windows", pilihan mode preview, dan "Lihat proyek" hanya berupa layer visual; file tidak menunjukkan tautan prototype. Karena fungsi utama halaman adalah mengarahkan ke installer, CTA unduhan tanpa tujuan nyata belum membuktikan alur utama (R-24, R-26, R-35). **Saran:** sambungkan nav ke section yang ada dan tombol unduh ke URL release installer yang benar; mode selector harus mengganti state/frame yang benar atau tampil sebagai pilihan visual yang tidak interaktif.

## Batas audit

- Ini audit file desain statis; tidak menjalankan landing page di browser dan tidak menguji breakpoint, tautan/prototype, keyboard, atau tombol unduh.
- SVG import belum dijalankan; keberhasilan konversi harus diverifikasi setelah izin perbaikan.
- Versi/URL installer aktual harus dicek sebelum CTA diarahkan ke release; label saat ini bertuliskan pratinjau 0.1.0.
- Working tree saat audit berisi `?? design/landing-page.moss-island.figcraft`; perubahan tersebut adalah file desain sesi sebelumnya. Tidak staging atau mengubah file itu dalam audit ini.
