# Audit setelah perbaikan sampul musik

antislop active: after (global preference).

Lingkup: pengambilan dan pemulihan sampul sesi media, bukan audit visual seluruh aplikasi atau audit Fokus.

## Temuan dan tindak lanjut

1. **HIGH, R-27: thumbnail terlambat tidak dipulihkan. Selesai.** `src/main.ts` sekarang memakai `src/audio/artworkRetry.ts` pada polling sesi yang sama. Jeda retry meningkat dari 1 hingga maksimum 30 detik, tidak menjalankan permintaan thumbnail paralel untuk identitas aktif, dan berhenti setelah berhasil. Ketersediaan thumbnail baru melewati cooldown. Bukti: tes 107, 108, 111.
2. **HIGH, R-27: hasil fallback kosong menghalangi pemulihan. Selesai.** `src/audio/lyricsService.ts` tidak menyimpan hasil kosong di cache; fallback gagal boleh dicoba lagi setelah 30 detik. Sampul fallback yang sudah tampil tetap dipertahankan saat thumbnail native berikutnya belum tersedia. Bukti: tes 109 dan inspeksi jalur `!applied` pada `src/main.ts`.
3. **HIGH, R-38: fallback lambat dapat menggantikan thumbnail sesi yang sudah berhasil. Selesai.** Hasil pencarian tidak diterapkan jika sampul sesi untuk identitas aktif sudah tersedia. Hasil rekaman lama tetap ditolak setelah lagu berganti. Cache pencarian yang dipakai ulang diberi identitas rekaman aktif. Bukti: tes 110, 112 dan tes lama 45, 48.
4. **Diagnostik: exception IPC pengambilan sampul tidak terlihat. Selesai.** `src/audio/systemMediaBridge.ts` mencatat warning ketika pemanggilan gagal. Hasil `null` tanpa exception tetap berarti sampul belum tersedia, bukan bukti kesalahan Spotify.

## Verifikasi

- PASS: `npm test`, 112/112 tes, termasuk enam tes regresi baru (107 sampai 112).
- PASS: `npm run build`, TypeScript dan Vite berhasil.
- PASS, R-35 untuk skenario sampul simulasi: aplikasi dijalankan di browser pada `http://localhost:1420/?tab=music`; sesi media dimock pada bridge aktual aplikasi, percobaan pertama mengembalikan `null`, percobaan kedua mengembalikan PNG uji. Gambar berhasil didekode di panel musik dan thumbnail compact (`naturalWidth = 1`), total dua permintaan. Console browser tidak mencatat error. Mock dikembalikan setelah pengujian.
- Integritas patch: `git diff --check` masih melaporkan whitespace lama pada `tests/test_suite.ts:1552`, di luar bagian yang diubah untuk tugas ini. Tidak diubah agar pekerjaan pengguna tetap utuh.

## Batas verifikasi

- Belum menguji Spotify desktop asli melalui GSMTC/IPC Windows. Simulasi browser tidak membuktikan sumber native memberikan thumbnail pada perangkat pengguna.
- Sampul masih berasal dari sesi media Windows; fallback menggunakan Deezer/iTunes, bukan Spotify Web API.
- Tidak ada perubahan layout, tema, kontrol playback, atau timer Fokus. Audit ini tidak menyatakan seluruh kontrol aplikasi telah diuji klik.
- Jika thumbnail Windows dan layanan fallback sama-sama tidak tersedia, placeholder tetap ditampilkan. Retry tidak menjamin sumber eksternal selalu menyediakan gambar.
