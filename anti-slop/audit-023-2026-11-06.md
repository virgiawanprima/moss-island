## 2026-11-06: Musim per sesi, sawit dan Momo tanpa aksesori

Permintaan: pengaturan musik hanya sumber pemutaran; musim berganti setiap selesai satu fokus; periksa perbedaan pohon; perbesar hutan sampai progress bar di bawah; ganti palem menjadi sawit. Permintaan earphone kemudian dibatalkan pengguna: hasil akhir Momo tanpa headset, earphone, atau kabel.

Perubahan: index.html menyisakan label/select/status sumber musik dan menghapus aksesori SVG. musicMomoView.ts tidak lagi memindahkan aksesori ke rig; aturan animasi aksesori dihapus, rig/reaksi Momo tetap. main.ts mempertahankan momoIntensity tersimpan meskipun UI dihapus. seasonCycle.ts mengatur rotasi semi → panas → gugur → dingin setiap fokus selesai dalam mode cycle. Skip, break dan manual tidak merotasi. Count lama tetap kompatibel tetapi tidak menentukan musim. Label tidak lagi menyebut enam sesi.

Hutan: canvas elastis, caption dan progress di baris bawah; render boleh membesar hingga1.35x sesuai ruang. Pada945px canvas405.69x215.39 dan progress bottom317 sama dengan body bottom317, berada di panel332. Panel fokus samping native ditetapkan560x640 agar hutan besar muat, tetap mengikuti batas workarea. Simulasi CSS560x640: progress bottom617.61 dan scroll/client638 sama. Tidak menjalankan Tauri.

Sawit: drawOilPalmTree, pelepah menyirip dan tandan merah-oranye. Kunci tersimpan palm dipertahankan, tidak menghapus pohon lama. Jenis aktual pisang, mangga, durian, sawit, jambu. Atlas20sprite aktual diperiksa; setiap spesies mempertahankan bentuk dan memiliki perbedaan bunga/buah/ujung daun/aksen salju dalam simulasi musim. Bukan model botani atau cuaca nyata. README diperbarui.

Verifikasi:178/178tes, build, ESLint dan diffcheck lulus. Tes26 memakai fungsi produksi untuk empat rotasi dan guard skip/break/manual. Tes175 memeriksa empat varian per jenis dan lima jenis berbeda pada tiap musim. E2E web sisa fokus1detik, Lanjut, beralih ke istirahat dan badge Panas·Setiap sesi fokus dari Semi. Pengaturan hanya sumber pemutaran terbukti di AX. Hutan5pohon diperiksa. Setelah earphone dihapus, DOM accessory0, rig tetap ada, klik memicu pose wave dan screenshot Momo polos. Seluruh fixture storage memori terisolasi. Native, volumeWindows, DPI dan reduced-motion OS belum diuji langsung.

Auto-review menolak perintah commit/push lama karena masih berisi earphone saat instruksi terbaru menghapusnya. Perintah tersebut tidak dijalankan. Kode diperbarui tanpa aksesori dan diuji ulang sebelum pengajuan push baru. Tidak mengakali penolakan. Gotcha: menghapus kontrol intensitas jangan mereset nilai tersimpan; palm adalah ID kompatibilitas sawit; zoom canvas perlu pemeriksaan tinggi panel/progress; instruksi terbaru mengubah hasil akhir sebelum publish.
