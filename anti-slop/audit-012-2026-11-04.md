# Acuan Figma dan bilah minimize mengambang

Pengguna menetapkan file Figma sebagai patokan visual, lalu memilih secara eksplisit: bentuk asli Figma dengan jalan tetap menghadap samping kiri/kanan. Pengguna juga meminta bilah minimize mengambang tidak tampak terpotong di atas. Laporan ini menggantikan arah gambar ulang detail dalam audit 011.

## Sumber desain yang benar-benar dibaca

- File: https://www.figma.com/design/vUeenpSEOc5vVat1vqDwYl/moss-island
- Halaman `0:1` diinspeksi dengan metadata setelah design context halaman tidak mengembalikan selection.
- `64:2208`, Momo / Original design · Motion atlas: design context dan screenshot.
- `64:2488`, Momo v2 / Idle, dan `64:3072`, Momo v2 / Walk: design context, screenshot dan motion context recursive.
- Idle dan Walk berisi delapan frame 64x64. Motion context melaporkan cohort 2000 ms dan translate stepped 0,-2,0 pada 0%,15%,30%; CSS idle diadaptasi langsung dari snippet. Atlas menyebut idle berjeda 1,8 detik dan walk stepped, tanpa morph.
- Idle asli menghadap depan; frame Walk Figma juga menghadap depan. Varian samping adalah adaptasi yang diminta pengguna, bukan klaim bahwa pose samping sudah ada di Figma.

## Aset dan implementasi

Delapan SVG idle diunduh dari URL yang dikembalikan get_design_context untuk dibandingkan. Semuanya identik geometri path dan fill dengan aset repo `src/assets/figma_svg/momo_v2/momo_v2_idle_01.svg` sampai `_08.svg`; root width/height 64 dan viewBox 0 0 64 64. Karena itu aset repo dipakai ulang melalui URL lokal build, bukan digambar ulang atau memakai URL Figma sementara. File SVG sumber tidak diubah. Salinan pembanding sementara dibersihkan sesudah pemeriksaan.

`src/desktopPet.ts`: front memakai delapan SVG asli melalui elemen SVG image berukuran 64x64. Idle menahan frame pertama 1800 ms lalu menjalankan frame berikutnya setiap 125 ms. Profil samping mengikuti empat warna asli (#71BA83, #C4F59B, #AF8055, #15221A), tunas/grid/proporsi sumber, tanpa outline tambahan, pipi atau highlight baru. Pose langkah dibuat stepped delapan fase dari jarak, memakai offset pixel bulat; bukan morph/rotasi interpolasi. Pengguna secara eksplisit meminta adaptasi samping ini.

`src/styles.css`: sprite dan wadah menjadi 64x64 pada skala 1x, dalam jendela pet tetap 76x92. Idle memakai snippet stepped 2 detik dari motion context. Frame memakai pixelated rendering. Bilah `floating + state-compact` mendapat border lengkap termasuk atas dan radius 18 px di keempat sudut; bentuk dock menempel tidak diganti.

`src/main.ts`: posisi expanded floating dibaca sebelum transisi agar minimize tidak memakai anchor lama. Native geometry writes ditandai dengan penghitung dan jeda event 250 ms; event resize programatis tidak diperlakukan sebagai drag. Pencatatan gerak pengguna tidak bergantung pada kueri tombol mouse yang bisa selesai setelah tombol sudah dilepas. Ada fallback capture pointerdown pada drag region. Modal/transisi dan pet otomatis tetap dilindungi.

`tests/test_suite.ts`: tes 159 diperluas untuk expanded floating; tes 167 memeriksa delapan aset lokal nonkosong berdimensi asli dan urutan/jeda idle.

## Delivery Gate dalam lingkup permintaan

- Hard Gate PASS: build dan 167 tes lulus; bilah utuh dan pet terlihat langsung di Tauri; aset lokal valid dan tidak ada URL Figma sementara di runtime.
- Purpose Gate PASS: Figma menjadi sumber bentuk dan warna; border lengkap hanya untuk floating; varian samping mengikuti pilihan eksplisit pengguna.
- Liveliness PASS: frame idle/kedip asli, pose berjalan kiri/kanan stepped dan perpindahan pelan dipertahankan, dengan arah ENERGY 1 / RHYTHM 2 / MOTION 2.
- Craftsmanship PASS dalam cakupan teruji: drag expanded, minimize, tombol sembunyi, idle dan dua arah berjalan diperiksa. Ukuran asli aset dipertahankan.

Belum mengukur FPS/frame time desktop, multi-monitor/DPI campuran, layar pendek/zoom atau reduced motion OS secara langsung. Semua gerakan atlas lain (wave/dance/plant/drink/sleep/celebrate) berada di luar perubahan pet ini. Panel lain yang berbeda dari Figma tidak diubah tanpa cakupan tambahan.
