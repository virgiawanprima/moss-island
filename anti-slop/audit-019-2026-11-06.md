# Bilah samping dan volume ringkas

Permintaan: selesaikan bilah minimize kiri/kanan yang terlalu tebal, panel expanded yang kurang rapi, dan volume ringkas.

## Perubahan

- CSS dan ukuran jendela Tauri compact samping: 96 menjadi 42 px, tinggi tetap 300 px. Timer vertikal, judul lagu disembunyikan pada bilah sempit, tombol disusun vertikal. Momo, indikator musik dan thumbnail tetap tersedia.
- Panel samping memakai lebar 560 px dengan header dua baris dan isi yang dapat bergulir. Perbaikan specificity pada header/panel Musik menghapus batas 48/156 px yang menyebabkan tumpukan. Ukuran angka fokus di dalam circle kembali 2rem.
- Ikon speaker setelah repeat membuka popover native HTML. Slider 120 px, label sumber dan persentase hanya terlihat saat dibuka. Posisi dijepit ke viewport; Escape/klik di luar menutup. Volume perangkat Windows dan volume musik bawaan tetap menggunakan alur sebelumnya.
- Popover terbuka memblokir hover auto-collapse. Tidak mengubah mode pet atau logika timer.

## Bukti aktual

178/178 tes, build, ESLint tanpa warning dan git diff --check lulus. Browser memakai fixture data memori terisolasi dari profil pengguna. Bilah kiri dan kanan diukur 42 x 300; pada kanan viewport1000, tombol berada x965.5–993.5 di dalam panel x958–1000. Expand/minimize bekerja. Panel Musik dan Istirahat diperiksa pada sisi kiri/kanan; CSS desktop disimulasikan di browser560x560. Circle, kebun, teks dan tombol tampil setelah transisi. Musik horizontal1000 dan480 juga diperiksa. Slider ArrowRight mengubah0 menjadi1%, buka ulang mempertahankan1%; Escape menutup dan fokus kembali ke speaker; klik Momo di luar popover menutup. Popover pada560 memiliki x376–552 dan pada480 x273–449, berada dalam viewport.

## Batas verifikasi

Tauri tetap ditutup. Simulasi CSS native bukan bukti jendela Tauri, DPI, multi-monitor atau volume Windows asli. Browser membatasi viewport minimum240px, sehingga bilah42px diuji sebagai elemen CSS di viewport1000, bukan viewport42. Pengaman hover dipasang berdasarkan kondisi popover terbuka; interaksi kursor native belum diuji. CI remote diperiksa terpisah setelah push.
