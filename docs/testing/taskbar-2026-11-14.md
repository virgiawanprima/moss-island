# Pengujian taskbar

Permintaan: uji perubahan `skipTaskbar: true` pada jendela utama di `src-tauri/tauri.conf.json`. Tujuan: menyembunyikan ikon taskbar sambil mempertahankan widget dan akses tray.

## Hasil aktual

- `npm test`: lulus 179/179.
- `npm run build`: lulus.
- `cargo test --lib`: 4 lulus, 3 ignored (jaringan/sesi media/perangkat audio); tidak menjalankan tes ignored.
- `cargo check` pada tugas implementasi sebelumnya: lulus; tidak diulang pada sesi pengujian ini.
- `git diff --check`: lulus, dengan peringatan normalisasi CRLF.
- `npm run tauri dev`: Vite melaporkan siap, tetapi Tauri terus menunggu localhost:1420; pemeriksaan TCP localhost gagal. Penyebab belum dipastikan. Sesi dev yang dibuat untuk pengujian dihentikan dengan Ctrl+C.
- `npm run tauri -- build --debug --no-bundle`: frontend lulus, build native gagal dengan `The paging file is too small for this operation to complete. (os error 1455)` saat membuat encoded metadata. Tidak mengubah pengaturan Windows. Executable debug tetap bertanggal 2026-11-09, sehingga bukan build perubahan ini.
- Akses UI alternatif berhasil menampilkan inventaris aplikasi, tetapi pemilihan jendela Opera berakhir dengan `Computer Use app approval timed out`. Runtime Computer Use awal juga gagal dengan `failed to launch codex app-server: program not found`.

## Batas dan tindak lanjut

Taskbar, Alt+Tab, interaksi tray, dan pemulihan widget belum diuji langsung. Tes unit/build frontend bukan bukti perilaku Windows shell. Setelah sumber daya build dan akses UI tersedia, buat build baru, jalankan, periksa taskbar dan Alt+Tab, lalu uji sembunyikan/tampilkan melalui tray serta shortcut Ctrl+Shift+M.

Gotcha: jangan menjalankan executable lama sebagai bukti perubahan konfigurasi baru setelah build gagal. Periksa waktu build dan hasil kompilasi terlebih dahulu.

Vault dapat dibaca, tetapi berada di luar direktori yang diizinkan untuk penulisan pada sesi ini. Catatan utama, handoff, gotcha, dan jurnal belum diperbarui. Laporan ini menjadi bahan sinkronisasi ke [[moss-island]], [[moss-island-handoff]], [[moss-island-gotcha]], dan [[moss-island-2026-11-14]] ketika akses tulis tersedia; rujukan balik dari vault belum dibuat.

Tidak melakukan staging, commit, atau mengubah berkas pengguna lainnya.

## Verifikasi lanjutan melalui Tauri

Permintaan lanjutan: gunakan Tauri untuk verifikasi. Menjalankan `npm run tauri -- dev --no-dev-server-wait --no-watch --config '{"build":{"devUrl":"http://127.0.0.1:1420"}}'` dengan `TAURI_DEV_HOST=127.0.0.1` hanya pada proses pengujian. Tidak mengubah konfigurasi alamat di repo.

- Vite siap di `http://127.0.0.1:1420/`.
- Tauri berhasil mengompilasi executable baru: `Finished dev profile ... in 40.83s`, kemudian `Running target\\debug\\tauri-app.exe`. Peringatan cache hard-link tetap muncul, tetapi kompilasi berhasil.
- Inventaris UI Windows mengonfirmasi jendela native berjudul `Moss Island`, ID 591910, pemilik `D:\projects_win\moss-island\src-tauri\target\debug\tauri-app.exe`.
- Pemilihan jendela tersebut untuk inspeksi berakhir dengan `Computer Use app approval timed out`. Tidak ada screenshot atau interaksi taskbar/Alt+Tab/tray yang berhasil pada sesi ini.
- Aplikasi Tauri dan sesi dev dibiarkan berjalan untuk pemeriksaan pengguna. Keberhasilan peluncuran ini menggantikan hambatan peluncuran dev sebelumnya, tetapi tidak membuktikan perilaku taskbar atau Alt+Tab.
- Sinkronisasi vault tetap tertunda karena tidak ada izin tulis ke direktori vault.

## Diagnosis ERR_NETWORK_ACCESS_DENIED lanjutan

Permintaan: perbaiki halaman WebView yang menampilkan ERR_NETWORK_ACCESS_DENIED.

Fakta terverifikasi:
- Lingkungan eksekusi menyediakan variabel CODEX_SANDBOX_NETWORK_DISABLED dan CODEX_WINDOWS_SANDBOX_PACKAGE_FAMILY.
- Invoke-WebRequest http://127.0.0.1:1420 dari terminal sesi gagal dengan pesan: An attempt was made to access a socket in a way forbidden by its access permissions.
- Pada pemeriksaan UI sebelumnya, WebView native menampilkan ERR_NETWORK_ACCESS_DENIED. Ini konsisten dengan pembatasan jaringan sesi; tidak ada bukti bahwa CSP aplikasi atau skipTaskbar menyebabkan error ini.
- Tauri dev berhasil dibangun dan diluncurkan. Memuat ulang WebView tidak mengatasi pembatasan akses.
- Percobaan cargo run --features tauri/custom-protocol dengan CARGO_BUILD_JOBS=1 gagal saat alokasi 1169915920 byte; bukan build frontend lokal yang berhasil. Percobaan nama fitur custom-protocol tanpa awalan tauri/ ditolak karena fitur itu tidak didefinisikan paket.
- Sesi uji dev terakhir milik agen (23870) dihentikan dengan Ctrl+C. Tidak menghentikan proses pengguna lain.

Tindakan: tidak mengubah firewall, antivirus, pembatasan sandbox, CSP, atau kode aplikasi untuk menyamarkan masalah lingkungan. Perubahan skipTaskbar pengguna tetap dipertahankan. Tidak mengulang tes unit karena tidak ada perubahan kode.

Tindak lanjut: pengguna menjalankan npm run tauri dev dari PowerShell biasa di D:\projects_win\moss-island, kemudian memeriksa apakah UI termuat. Hasil di luar sesi terbatas belum diverifikasi. Jika masih gagal, diagnosis pembatasan sistem lain diperlukan berdasarkan hasil tersebut.

Gotcha: server Vite berstatus ready dan kompilasi Tauri berhasil tidak membuktikan WebView dapat mengakses loopback dalam sesi dengan jaringan dibatasi. Jangan mencoba menghindari pembatasan dengan peluncur alternatif atau menonaktifkan perlindungan Windows.

Sinkronisasi [[moss-island]], [[moss-island-handoff]], [[moss-island-gotcha]], dan [[moss-island-2026-11-14]] tetap tertunda: vault di luar direktori tulis yang diizinkan. Laporan repo ini menyimpan fakta untuk sinkronisasi berikutnya; tidak mengklaim vault diperbarui.
