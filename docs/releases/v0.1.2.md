# Moss Island v0.1.2

Jendela utama memakai `skipTaskbar: true` agar widget tidak memiliki tombol aplikasi di taskbar Windows. Widget dan akses melalui tray tetap tersedia dalam implementasi.

Momo menjelajahi petak kosong pulau secara acak dan melakukan kegiatan santai bergantian dengan berkebun. Perawatan tunas dijadwalkan tiap 60 detik aktif, pohon tiap 90 detik. Aktivitas diam menghentikan jalan; perawatan menyela kegiatan santai. Render tubuh dan aksesori memakai grid piksel yang sama. Tauri horizontal diperiksa langsung: Momo berpindah dari area tunas ke tengah dan tepi kiri. Keenam aktivitas santai lulus pada simulasi renderer, belum seluruhnya diamati langsung. Seluruh 183 tes, build frontend dan lint lulus. Detail pengujian tersedia di `docs/testing/momo-focus-2026-11-14.md`.

## Verifikasi dan batas

- Aktivitas menanam Momo dihapus atas permintaan pengguna. Tunas langsung muncul saat Fokus dimulai; kunjungan awal hanya menyiram dan memupuk. Pertumbuhan dan penambahan pohon tetap mengikuti penyelesaian Fokus.

- Pengguna mengonfirmasi sudah menguji taskbar dan Alt+Tab secara langsung dan hasilnya benar. Pemeriksaan UI otomatis agen tidak selesai; pemulihan lewat tray belum dikonfirmasi secara terpisah.
- Peluncuran Tauri dev sebelumnya berhasil, tetapi WebView dalam sesi pengujian dengan jaringan dibatasi menampilkan `ERR_NETWORK_ACCESS_DENIED` saat memuat server lokal. Ini bukan perbaikan firewall atau akses jaringan.
- Validasi lokal: 183/183 tes logika, 30/30 tes layout Edge, lint, build frontend, cargo check, dan tes Rust (4 lulus, 3 ignored). Tes layout menggunakan fixture DOM/CSS aplikasi, bukan integrasi Spotify desktop. Installer belum diuji pada instalasi Windows bersih.

Rincian pengujian: `docs/testing/taskbar-2026-11-14.md`.
